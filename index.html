Content pattern

Clear content hierarchy for every section

Use a short orange eyebrow to introduce the topic, followed by an H2 and a stronger lead paragraph that communicates the main message quickly.

Supporting body copy should provide the detail without competing with the headline. Keep paragraphs concise, use comfortable line lengths, and maintain consistent vertical spacing so content remains easy to scan across both marketing pages and product interfaces.

Content with image

Pair strong content with supporting imagery

Use a balanced two-column layout when an image helps explain the story, product or outcome without overwhelming the written content.

The image should use the same rounded corners, border treatment and visual language as other cards. Keep the eyebrow, heading and paragraph hierarchy consistent with standard content sections so pages feel cohesive.

Usage rules

  • Use one icon style consistently, outlined Lucide icons.
  • Match icon colour to meaning, not decoration.

Help & guidance

Frequently asked questions

Use a simple accordion for FAQs. Keep questions concise, answers easy to scan and use the orange accent only for the active state.

How quickly can an integration go live?
Many standard integrations can be configured quickly using existing connectors and solution templates. More complex requirements may need additional discovery, transformation and testing.
Which systems can Zynk connect?
Zynk connects accounting, ecommerce, CRM, ERP, warehouse and other business platforms. The exact capabilities depend on the connector and workflow required.
Can workflows be customised?
Yes. Workflows can include mapping, transformation, validation and business rules so data moves between systems in the format each platform expects.
What happens if an integration fails?
Errors should be surfaced clearly through logs and status information so the cause can be identified and the affected workflow investigated.

Guidance: Prefer one open item at a time on marketing pages, keep answers to a few short paragraphs, and avoid placing every FAQ inside an individual card.

Brand effect

Zynk Aurora

This is the exact .glow-hero effect used by the Zynk website. It combines four blurred radial gradients and slowly drifts and scales them using transform-only animation.

Live website effect

The exact Zynk glow-hero treatment

The orange, magenta, violet and cyan blooms overlap behind the page header. A bottom mask fades the glow out before the clipping boundary so there is no hard edge.

Orange

rgb(249 115 22 / .55)

Magenta

rgb(217 70 239 / .42)

38% × 50% at 56% 14%, fades by 62%.

Violet

rgb(139 92 246 / .40)

34% × 48% at 82% 26%, fades by 62%.

Cyan

rgb(56 189 248 / .34)

40% × 52% at 10% 30%, fades by 64%.

global.css
.glow-hero {
  background-image:
    radial-gradient(40% 55% at 28% 22%,
      rgb(249 115 22 / 0.55) 0%, transparent 60%),
    radial-gradient(38% 50% at 56% 14%,
      rgb(217 70 239 / 0.42) 0%, transparent 62%),
    radial-gradient(34% 48% at 82% 26%,
      rgb(139 92 246 / 0.40) 0%, transparent 62%),
    radial-gradient(40% 52% at 10% 30%,
      rgb(56 189 248 / 0.34) 0%, transparent 64%);
  filter: blur(56px);
  animation: aurora-drift 12s ease-in-out infinite alternate;
}

@keyframes aurora-drift {
  0%   { transform: translate3d(-12%, -4%, 0) scale(1.2); }
  50%  { transform: translate3d(8%, 4%, 0) scale(1.4); }
  100% { transform: translate3d(12%, -2%, 0) scale(1.3); }
}

@media (prefers-reduced-motion: reduce) {
  .glow-hero { animation: none; }
}

Live placement

The website does not use .glow-hero alone. The containing element and mask are part of the effect. 

<div class="
  pointer-events-none
  absolute inset-x-0 top-0

">

Rule: Treat these values as the canonical Zynk Aurora. Do not substitute a simplified two-colour gradient or change the blur, opacity, animation timing, transform values or mask unless the design system is intentionally revised.

Code blocks

Use a monospace font for code, keep the background dark in both themes and give examples enough padding and line-height to remain easy to scan.

Code style

  • Font: font-mono
  • Size: 14px / text-sm
  • Line height: 165%
  • Background: neutral-950
  • Text: neutral-200
  • Padding: p-5
  • Corners: rounded-2xl

Inline code should use the same mono font at the surrounding text size, with a subtle neutral background: bg-neutral-100 dark:bg-neutral-800

06. Content pattern

Use a short orange eyebrow to introduce the topic, followed by an H2 and a stronger lead paragraph that communicates the main message quickly.

13. Product icons

Product and platform icons represent third-party brands such as Shopify, Sage, HubSpot and Xero. Treat them as brand assets, not UI icons. Use SVG wherever possible and source approved assets from Dashboard Icons before looking elsewhere.

Preferred source

Search Dashboard Icons first. It provides product/service logos in SVG, PNG and WEBP, with light/dark variants for many brands.

Browse Dashboard Icons

Format priority

  1. 01SVG preferred for all scalable product icons.
  2. 02PNG / WEBP only when an SVG is unavailable.
  3. 03Use the vendor's official asset if Dashboard Icons does not contain the product.

Do not

  • Do not replace a product logo with a Lucide icon.
  • Do not redraw, recolour or distort a third-party brand mark.
  • Do not place raster icons at sizes that make them visibly soft.

Help & guidance

16. Frequently asked questions

Use a simple accordion for FAQs. Keep questions concise, answers easy to scan and use the orange accent only for the active state.

How quickly can an integration go live?
Many standard integrations can be configured quickly using existing connectors and solution templates. More complex requirements may need additional discovery, transformation and testing.
Which systems can Zynk connect?
Zynk connects accounting, ecommerce, CRM, ERP, warehouse and other business platforms. The exact capabilities depend on the connector and workflow required.
Can workflows be customised?
Yes. Workflows can include mapping, transformation, validation and business rules so data moves between systems in the format each platform expects.
What happens if an integration fails?
Errors should be surfaced clearly through logs and status information so the cause can be identified and the affected workflow investigated.

Guidance: Prefer one open item at a time on marketing pages, keep answers to a few short paragraphs, and avoid placing every FAQ inside an individual card.

}

@keyframes aurora-drift {
  0%   { transform: translate3d(-12%, -4%, 0) scale(1.2); }
  50%  { transform: translate3d(8%, 4%, 0) scale(1.4); }
  100% { transform: translate3d(12%, -2%, 0) scale(1.3); }
}

@media (prefers-reduced-motion: reduce) {
  .glow-hero { animation: none; }
}

Marketing creative

22. Social media graphics

Social graphics should look like Zynk pages translated into a fixed canvas: Neutral structure, Orange emphasis, Inter Tight 700 headlines, Lucide icons, restrained imagery and generous spacing. Keep each graphic focused on one message. Examples are theme-aware: light mode uses neutral-50/white with black headings, while dark mode uses neutral-900 with white headings. Headings must always be a single colour.

Typography

Inter Tight 700 for headlines. Inter for supporting copy. Keep text large enough to scan at feed size.

Colour

Neutral backgrounds and surfaces, Orange 500 for emphasis and CTAs. Semantic colours only when they carry meaning.

Icons

Lucide only. Use 24–32px icons in social artwork and keep stroke style consistent.

Composition

One primary message per visual. Prefer strong hierarchy and whitespace over decorative clutter.

Logo

Use the official Zynk SVG on every social graphic at h-10 (40px). Place it top left; invert only on light artwork backgrounds.

Heading colour

Use one colour per heading. Black on light artwork, white on dark/image artwork. Never highlight individual heading words in orange.

Theme

Square social templates use a dark neutral-900 background only. Non-square social formats may use the documented light/dark treatments where specified.

Presentation system

23. Slide presentations

Use standard 16:9 widescreen slides. Presentation slides are deliberately simpler than website sections: start with the title, avoid eyebrows, reduce chrome and let typography, imagery and whitespace do most of the work.

Aspect ratio

Use 16:9 widescreen for every standard Zynk deck.

Typography

Inter Tight 700 for titles. Inter for supporting copy.

  • Title: 48–64px
  • Slide heading: 36–48px
  • Body: 20–26px
  • Footnotes: 12–14px

Slide rules

  • No eyebrows on presentation slides.
  • One idea per slide.
  • Prefer fewer, larger elements over nested cards.
  • Zynk logo: top left on the first slide; bottom right on every other slide.
